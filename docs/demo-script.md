# Demo Script

## Hook

Imagine you are a new intern joining a project. The repo is public, the README exists, but you still do not know where to start or what first PR would be safe.

## Walkthrough

1. Open RepoQuest.
2. Paste a GitHub repository URL or load the prepared TodoMVC demo.
3. Show the repository overview, tech stack, key files, and architecture map.
4. Open the mission dashboard and select one beginner mission.
5. Show mentor hints, relevant files, and suggested tests.
6. Show the first PR plan with implementation steps, test plan, and reviewer checklist.
7. Open the readiness report and difficulty radar.
8. End on the public GitHub repo and the `bob_sessions/` folder with exported IBM Bob task reports.

## Closing Pitch

RepoQuest helps new developers go from an unfamiliar codebase to a meaningful first pull request. IBM Bob provides repository-level understanding, validates the architecture map, generates guided missions, suggests tests, and prepares a reviewer-ready PR plan. The result is faster onboarding for interns, open-source contributors, and new engineering hires.
