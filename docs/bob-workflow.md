# IBM Bob Workflow

Use this workflow inside IBM Bob IDE so the judges can clearly see Bob as a core part of RepoQuest.

## Task 1: Repository Analysis

Prompt Bob with the repo URL and ask it to identify:

- project purpose
- tech stack
- key folders
- important files
- entry points
- setup commands
- test conventions
- beginner-safe contribution areas

Export the task history markdown and task session consumption screenshot into `bob_sessions/`.

## Task 2: Mission Generation

Ask Bob to generate five onboarding missions:

- mission title
- beginner or medium difficulty
- objective
- relevant files
- progressive hints
- suggested test
- learning outcome

Export the task history markdown and task session consumption screenshot into `bob_sessions/`.

## Task 3: First PR Plan

Ask Bob to recommend the safest meaningful first pull request:

- PR title
- files to touch
- implementation steps
- risk notes
- test plan
- reviewer checklist

Export the task history markdown and task session consumption screenshot into `bob_sessions/`.

## Task 4: App Build Evidence

Use Bob while refining this prototype. Good tasks to capture:

- improve UI copy
- validate the scoring model
- review the generated mission structure
- suggest tests
- generate the final README or demo script

Export all relevant Bob task reports before submission.
