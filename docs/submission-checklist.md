## Short Description

RepoQuest turns a GitHub repository into a guided onboarding journey that helps new developers understand the codebase and prepare a safe first pull request with IBM Bob.

## Long Description

RepoQuest is a first-PR simulator for developers entering an unfamiliar codebase. A user enters a GitHub repository URL, and RepoQuest generates a repository overview, architecture map, guided onboarding missions, mentor-style hints, test suggestions, a contribution difficulty radar, and a first pull request readiness report.

IBM Bob is central to the workflow. Bob analyzes repository structure, identifies important files and workflows, validates mission content, suggests tests, and helps prepare a reviewer-ready PR plan. The project is designed for interns, new engineering hires, open-source contributors, and hackathon teammates who need to understand a codebase quickly and contribute with confidence.

The MVP includes a polished browser-based demo, live GitHub repository tree analysis, prepared fallback output, and a `bob_sessions/` folder for exported IBM Bob task reports and consumption screenshots required for judging.
